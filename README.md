# Hi, I'm Weikai 👋

I'm a finance professor at the City University of Hong Kong — empirical asset pricing, behavioral finance, and ESG. With coding agents, I turn my research and teaching workflows into open tools: simulated peer review, R&R response handling, market-case decks for class. Code is my research assistant; it works nights and never asks for coauthorship.
